# 设置页面重构计划

## 目标
- 打开“设置”时，窗口大小与主舞台一致：860 × 660，最小尺寸 720 × 560。
- 设置页只保留高频用户任务：模型配置、记忆库/Vault 绑定、必要状态提示。
- 删除/隐藏低频且扰乱首屏的信息：独立智能体模型配置、多轮协商设置、过多状态明细。
- 让用户第一眼知道要做什么：先配模型，再绑定记忆库。

## 实施步骤
1. 调整 Electron 控制窗口尺寸
   - 在 `apps/desktop/electron/windows.js` 提取/复用主舞台尺寸常量。
   - 将控制窗口默认大小和最小大小改为与主舞台窗口一致。
   - 保持现有 `openControlWindow("settings-panel")` 入口不变，降低改动范围。

2. 重构设置页组件
   - 修改 `apps/desktop/src/features/settings/SettingsPanel.tsx`：
     - 标题改为更清晰的“设置”。
     - 增加简短引导区，突出“1 配置模型 / 2 绑定记忆库”。
     - 保留 `ModelHealthBanner`、`GlobalModelCard`、`VaultBindingSection`。
     - 移除首屏中的“独立智能体模型配置（高级）”和“多轮协商”区域。
   - 保留父级传入的回调类型暂不大规模清理，避免牵连 `useSettings`、API 类型和后端逻辑；只从 UI 移除入口。

3. 简化模型配置卡片
   - 修改 `GlobalModelCard.tsx`：
     - 文案改成用户能理解的“AI 模型”。
     - 减少解释文字和状态网格噪音。
     - 只保留保存、测试连接、当前测试/保存提示。

4. 简化 Vault 绑定卡片
   - 修改 `VaultBindingSection.tsx`：
     - 标题改为“记忆库位置”。
     - 主按钮文案改为“保存位置”。
     - 将“状态”“索引”“当前 Vault / 最近索引”折叠到“高级操作”里，默认不干扰首屏。

5. 调整样式
   - 修改 `apps/desktop/src/styles.css`：
     - 设置页改为适配 860 × 660 的单列布局。
     - 设置页卡片间距更小、层级更清晰。
     - 保留响应式规则，避免小窗口横向溢出。

6. 验证
   - 运行 `npm run typecheck`（工作目录 `apps/desktop`）。
   - 如时间允许再运行 `npm run build`。

## 不做的事
- 不删除后端设置能力，不改数据库/接口。
- 不移除独立智能体模型、多轮协商的业务逻辑，只从当前设置页首屏移除，后续如需要可放到开发者/高级入口。
