# Product

## Register

product

## Users

Windows users who want a local-first AI companion for everyday conversation, personal memory, notes, reminders, and knowledge retrieval. They need to move between a quick desktop interaction and a focused workspace without losing context or control of local data.

## Product Purpose

Agent Pet turns conversation into a durable, reviewable personal memory workflow. It should answer from the user's local records when evidence exists, make the source and uncertainty clear, and keep routine desktop work in one coherent application window.

## Brand Personality

Calm, trustworthy, companionable. The interface should feel like a focused personal workspace: warm in language, restrained in chrome, and explicit about what is known versus inferred.

## Anti-references

Avoid window-per-feature desktop behavior, long unstructured text blocks, unexplained retrieval jargon, decorative card stacks, and UI that implies a memory exists when the local record was not actually found.

## Design Principles

- Conversation is the entry point; memory evidence should support it without taking over the surface.
- One desktop home should own feature navigation and preserve continuity between views.
- Local records, dates, and uncertainty are visible through plain language rather than implementation details.
- Dense information is grouped into readable hierarchy, with progressive disclosure for trace and audit details.
- Privacy, keyboard access, contrast, and reduced motion are part of the default workflow.

## Accessibility & Inclusion

Target WCAG 2.1 AA for text contrast and keyboard focus. Keep Chinese and English text readable at normal desktop sizes, allow content to wrap without overlap, expose meaningful labels to assistive technology, and provide a reduced-motion path for animated states.
