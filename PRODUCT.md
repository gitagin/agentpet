# Product

## Register

product

## Users

Agent Pet is for everyday Chinese-speaking Windows users who want a local desktop companion that can chat, remember useful context, and help organize personal notes without making the interface feel like an admin console.

## Product Purpose

The product provides a local-first AI companion with auditable long-term memory, Markdown/Vault organization, reminders, and model settings. The primary surface should make chatting, reviewing memory, and entering settings immediately visible while keeping supporting workflows secondary.

## Brand Personality

Warm, trustworthy, and quietly capable. The companion should feel present and helpful, but the UI must stay calm enough for repeated daily use.

## Anti-references

Avoid generic SaaS dashboards, dense developer tooling, decorative AI-purple gradients, white overlays that hide the stage artwork, and layouts that bury the bottom navigation or require users to scroll the main pet stage.

## Design Principles

1. Preserve the pet-stage feeling before adding new UI density.
2. Keep primary navigation visible and stable at all times.
3. Treat memory and automation as auditable product features, not decorative content.
4. Use restrained surfaces so the background and Live2D character remain part of the experience.
5. Favor predictable product controls over experimental affordances.

## Accessibility & Inclusion

Target WCAG AA contrast for text and controls. Respect reduced motion, keep touch targets comfortable, and avoid relying on color alone for state. Renderer code must stay inside the Electron contextBridge IPC boundary.
