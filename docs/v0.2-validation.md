## Product Boundary

v0.2 is an AI Companion release, not only a Wiki release:

```text
AI Companion v0.2 = Journal-first, Wiki-assisted companion alpha release.
```

The v0.2 product boundary is:

- Companion memory can use daily chat archive, structured diary memory, long-term personal memory, and deterministic multi-source retrieval before chat generation.
- Continuity state can influence prompt context and desktop presence display only after review-gated confirmation.
- Wiki workflows use proposal/review/apply for durable Vault writes.
- Desktop remains local-first: renderer capabilities go through contextBridge IPC, backend APIs stay protected by bearer token, and real Vault Markdown writes require explicit user confirmation.
- v0.2 is allowed to keep signed installers, auto-update, voice, full Live2D lip sync, complex motion orchestration, multi-character support, cloud sync, and plugin marketplace out of scope.

## Manual Electron Trial

Run after the automated gate:

```powershell

```

Required observations:

1. Desktop pet appears and the control console can be opened.
2. Health check succeeds or shows a categorized Chinese error.
3. Existing sidecar state can restore the active Vault when the same Electron-managed state directory is reused.
4. Model settings can be saved and tested without exposing the API key.
5. Chat emits visible status/tool/citation/token/done states in the control window.
6. Long replies remain readable through compact bubble pagination and do not resize the fixed bubble.

10. Closing Electron leaves no unintended sidecar or Electron process behind.

Record any failure as `Partial` unless it blocks startup, control-console access, protected API access, or data safety. Blocking failures prevent `v0.2-rc1`.
