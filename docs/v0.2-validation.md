## Current Product Narrative

当前产品叙事已经从多能力入口收敛为“本地长期记忆陪伴体”：

```text
本地长期记忆陪伴体 = 桌宠入口 + 自然聊天 + 本机长期记忆 + 可查看、可修改、可撤回的记忆控制。
```

当前体验边界是：

- 首屏应先让用户感到这是一个会长期陪伴、记住重要内容的本地陪伴体。
- 聊天入口应鼓励用户自然说话，而不是先选择工程工具或配置系统。
- 记忆页是信任核心，应展示记住了什么、来源、状态，以及撤回或复核入口。
- 知识整理、提醒、资料归档、复盘报告、模型配置和调试诊断都是内置支撑能力，不应抢占首屏和普通聊天路径。
- 后端回答应在相关时检索聊天日记、长期记忆和知识整理内容；没有依据时不能编造记忆。
- 低风险自动整理必须留下活动记录；高风险、敏感、低置信或关系身份类内容仍必须确认或跳过。
- 桌面端仍保持本地优先权限边界：渲染进程能力经过 contextBridge IPC，受保护 API 由本地会话令牌保护。
