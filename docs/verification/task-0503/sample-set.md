## Labels

- `over-recall`: memory was brought in when it was not needed, felt intrusive,
  or overclaimed certainty.
- `under-recall`: relevant memory existed but was missed or ignored.
- `stiff`: memory was relevant but phrasing felt like a retrieval paste or
  support transcript.
- `natural`: memory was relevant, proportionate, and phrased like a companion.

## Score Fields

Each score is 1 to 5:

- Relevance: did the recalled memory help the current user message?
- Naturalness: did the reply sound conversational instead of mechanical?
- Boundary: did the reply avoid raw snippets, paths, status markers, and unsafe
  or unconfirmed claims?
- Helpfulness: did the memory improve the answer?
