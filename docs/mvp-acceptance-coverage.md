# MVP Acceptance Coverage Matrix

Date: 2026-08-14
Executor: LLM Wiki release evidence review
Last reconciled: 2026-08-14 against current runtime entrypoints, migrations,
tests and `output/verification/LLMWIKI-*` artifacts.

This matrix is a current evidence index for the local, single-user LLM Wiki and
memory graph MVP. It is not a historical completion log. Current code and named
verification output take precedence over old manual notes, provider campaigns or
superseded task identifiers. A mechanism marked `Covered` does not imply a
business KPI, 24-hour availability or a clean Windows/DPI release gate.

Status legend:

- `Covered`: the named current mechanism and its focused test/evidence exist.
- `Partial`: a mechanism exists, but an injection, visual, environment or time
  boundary is still unverified.
- `Gap`: the acceptance outcome is not implemented or has no current entrypoint.
- `Out of scope`: explicitly excluded from this local single-user MVP.
